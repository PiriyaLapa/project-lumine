## Lessons Learned

- **When a user names a specific external tool by brand (Draw.io, Lucidchart, Jira, etc.), check tool availability via ToolSearch before describing any plan** — not after starting to plan. Committing to an approach and then discovering a capability gap forces a course-correction the user has to sit through; checking first lets the constraint shape the plan from the start.
- **A document meant to "hand off context" (like BA-SA_Transition_Context.md) is a snapshot, not a live index** — when it references a Notion page_id as the source for a topic, the actual content may have moved to a child/sibling page since the doc was last updated. Search Notion by keyword in addition to trusting the referenced page_id, especially for docs more than a few days old.
- **Before regenerating any artifact from a stale source (Notion draft, an old doc, a cached summary), diff it against the current live source (codebase, database, config) if that live source is reachable** — this is the same "verify before reporting" discipline used in `/recap`, but it generalizes past recap: any time you're about to hand someone a deliverable built from a description of a system, and the actual system is available to check, check it.
